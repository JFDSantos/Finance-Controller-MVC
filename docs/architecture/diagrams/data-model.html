Três tabelas. Income e Expense ficam na mesma tabela Moviments, separadas pela coluna discriminadora Type. Apagar um usuário apaga em cascata as categorias e os movimentos dele; apagar uma categoria com movimentos é bloqueado pela chave estrangeira.

Arraste o diagrama para o lado para ver tudo.

Fonte: Finance.Infrastructure/Data/FinanceContext.cs e Migrations/FinanceContextModelSnapshot.cs. Moviment é abstrata (TPH). O filtro por usuário é um HasQueryFilter do EF Core, não uma regra do banco. Role é o enum EUserRole gravado como inteiro.
