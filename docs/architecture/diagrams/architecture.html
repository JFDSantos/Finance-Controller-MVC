Arquitetura em camadas

Uma requisição do navegador passa pelo proxy do Render, pelo pipeline de middlewares da API, pelos controllers, pelos services e pelo FinanceContext até o PostgreSQL. A mesma API serve o build do React a partir de wwwroot. Todas as camadas apontam para Finance.Domain.

Arraste o diagrama para o lado para ver tudo.

Fonte: Finance.API/Program.cs (ordem do pipeline), Finance.Infrastructure/Data/FinanceContext.cs (HasQueryFilter em Category e Moviment), referências dos .csproj. A Infrastructure implementa as interfaces da Application (IBaseRepository, IUnitOfWork); a API é a raiz de composição e referencia as três outras camadas.
